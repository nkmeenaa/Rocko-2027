# Rock-o-Phonix '27

Landing page for **Rock-o-Phonix '27**, the rock band competition at Alcheringa, IIT Guwahati.
Design by Team Creatives, built by Team WebOps. React + Vite, served by the Django app in this repo.

It is a 1:1 build of the approved prototype (`RockOPhonix27_WebOps_Handoff/site/index.html`),
with a mobile layout added.

---

## How it fits into the Django repo

```
Rocko-2027/
  frontend/                 ← this React project (source)
  server/static/landing/    ← the built site (generated by `npm run build`, committed)
  server/views.py           ← `landing` view returns server/static/landing/index.html
  server/urls.py            ← "/" = landing page, "/register/" = registration form
```

The Register button links to `/register/`. The registration page's "← Homepage" link goes back to `/`.

## Work on the landing page

Needs Node.js 18+ (frontend) and Python 3 (Django).

```bash
cd frontend
npm install          # first time only
npm run dev          # http://localhost:5173 — live reload while you edit
npm run build        # writes the site into ../server/static/landing/
cd ..
python manage.py runserver   # http://127.0.0.1:8000/ shows the landing page
```

**Every time you change something in `frontend/`, run `npm run build` and commit
`server/static/landing/` too.** Django serves the built files, so it never needs Node.

The browser blocks sound until the first click, so the intro usually waits on **ENTER**.

## Going live (production)

With `DEBUG = False`, Django stops serving static files by itself. Two options:

* **WhiteNoise** (simplest): `pip install whitenoise`, then add
  `"whitenoise.middleware.WhiteNoiseMiddleware"` right after `SecurityMiddleware`, and set
  `STATIC_ROOT = BASE_DIR / "staticfiles"`. Then run `python manage.py collectstatic`.
* Or let the web server (nginx) serve `/static/` from `STATIC_ROOT`.

Also add your domain to `ALLOWED_HOSTS`.

## Where things are

```
public/assets/          every image / video / audio the page loads (served as-is)
src/
  data/content.js       ALL copy, links, timeline, FAQ, songs, contact. Edit text here.
  components/           React markup for each section
    Loader.jsx          intro overlay (removed when the intro ends)
    Chrome.jsx          home logo, section rail, Register, sound toggle
    Hero.jsx            hero clip, flashes, logo, lightning canvas
    AboutTimeline.jsx   CD shatter → skull clock → needle sweep (one pinned scene)
    Drums.jsx           drum kit, setlist, beat line
    Gallery.jsx         6-tile strobe grid
    Faq.jsx             single-open accordion (React state)
    Footer.jsx, Icon.jsx
  effects/              the animation engines (plain JS, run once after React mounts)
    loader.js           4s intro synced to the music
    hero.js             video glitch partitions, stage flashes, light beam, scroll-out
    lightning.js        bolts released from the logo's real edge pixels
    story.js            shatter scrub, About reveal, needle + dates, sweep mask
    drums.js            Web Audio drum synth, hit flashes, beat trainer
    scroll.js           the single rAF loop, gallery strobe, rail active state
  lib/core.js           helpers, artboard scaling, layout mode, shared sound state
  styles/global.css     all styles; desktop first, then the MOBILE block, then reduced motion
```

**Why engines + components?** React renders the structure and the content. The
scroll-scrubbed animation, canvases and audio run in plain JS on top of that DOM, as in the
prototype. Every engine returns a cleanup function, so it is safe with React StrictMode and hot reload.

## How the page works

* Each pinned section is a tall scroll track holding a **sticky full-screen stage**. Inside the
  stage is the Figma artboard, scaled to fit the screen:
  * desktop: **1440×1024**
  * mobile (≤767px): **430×932**
* One `requestAnimationFrame` loop (`effects/scroll.js`) reads scroll progress and updates only the
  sections near the viewport. Every animation is scrubbed by scroll, so scrolling back plays it in reverse.
* FAQ and footer are normal page flow.

| Section | Track | What scroll does |
|---|---|---|
| Hero | 260vh | video blurs + dims, fades to black, then the logo blurs away |
| About + Timeline | 1460vh | CD spins in → shatter clip scrubbed, About text appears on the crack frame → skull clock, needle walks 5 dates → hold → needle's full turn wipes the skull and reveals the drums |
| Drum kit | 720vh, overlapping the clock by −520vh | playable: keys A S D H J K L + Space, or tap |
| Gallery | 320vh | checker strobe chase |

Positions in `global.css` and the engines use **Figma px on the artboard**. If you move the kit
or the clock, also update `KIT` in `effects/drums.js`. The clock hub is at (313, 505) in the skull frame.

## Mobile

Phones use their own 430×932 artboard, stacked top to bottom:

| Screen | Layout |
|---|---|
| Hero | logo centred |
| About | the CD fills about 90% of the width |
| Timeline | skull clock at the top, date copy under it |
| Drums | kit, then the beat line, then the setlist in 2 columns. Tap the glowing drum. |
| Gallery | 2×3 grid |

The rail shows dots only, and keyboard hints are hidden on touch screens.
⚠ There is no mobile design in Figma yet for About, Timeline and Drums. This layout is a proposal for Team Creatives to review.

## Music sync

* `backinblack.mp3` starts 1.70s into the original track, so the drumstick count-in plays under the loader.
* The riff hits at **4.085s**, which is when the hero opens. To change this, re-trim the mp3 and update `HIT` in `effects/loader.js`.
* ⚠ Playing "Back in Black" on a public site needs licensing clearance from the festival. The drum
  trainer's song names (Queen, The White Stripes, AC/DC, Metallica) should be cleared too.

## Performance rules (please keep)

* No `mix-blend-mode` or SVG filters on full-screen layers. The hero grade is baked into `hero-graded.mp4`.
* Only write styles when the value changes. Off-screen sections do no work.
* Lightning canvas DPR ≤ 1.25.
* `shatter.mp4` must stay all-intra so it can be seeked by scroll: `ffmpeg -i in.mp4 -g 1 -an shatter.mp4`
* `prefers-reduced-motion` turns off lightning, strobes, flickers and loops. Scrolling and the accordion still work.
